# Assignment: GitHub Account Verification

**Due Date:** Friday, August 28, 2026

## Objective
Throughout this course, we will use GitHub to manage code, submit assignments, and host course materials. Your first task is simply to ensure you have a working GitHub account and to share your username with the instructor so you can be added to the course organization (`JMU-Data`).

## Instructions

1. **Create or Log In to GitHub**
   - If you do not have a GitHub account, go to [GitHub.com](https://github.com/) and create one. 
   - *Note: You are not required to use your JMU email address for GitHub, but you may if you prefer.*
   - If you already have a GitHub account, simply log in.

2. **Locate Your Profile URL**
   - Go to your GitHub profile page (click your profile picture in the top right and select "Your profile").
   - Copy the URL from your browser's address bar. It should look like this: `https://github.com/your-username`.

3. **Submit Your Information**
   - Go to the course Canvas page.
   - Navigate to the **Assignments** section and find "GitHub Account Verification".
   - Submit the following two pieces of information in the text box:
     1. Your GitHub Username (e.g., `janedoe`)
     2. Your GitHub Profile URL (e.g., `https://github.com/janedoe`)

*Note: You do not need to create any repositories or write any code for this assignment. Further setup will be handled in subsequent weeks.*
