4. Answer all four questions — 40 points

Q1. Which ten collected tweets have the most likes? — 10 points

Create a pandas table with Tweet text on the left and Likes on the right. Display up to 10 unique tweets, ordered from highest to lowest tweet.public_metrics.like_count.

  • Show the complete tweet.text, without truncating it.
  • Count each tweet.id once. If a tweet appears more than once, use its highest stored numeric like count.
  • Use a consistent order for tied counts, such as sorting by tweet.id.

Example format — fictional teaching data, not tweets to use in your submission:

Tweet text Likes
Our class compared three ways to visualize the same dataset today. 120
A clear chart title makes the main comparison easier to understand. 85
I used Python to turn my query results into a table. 44

Your table should contain your own results, with up to ten rows. In the Markdown answer, describe what the most-liked posts discuss. These likes are stored values from collection time, not live counts.

Q2. Which ten users in your collection have the most followers? — 10 points

Create a horizontal bar chart for up to 10 distinct users, ranked by user.public_metrics.followers_count.

  • Label the bars with user.username and the numeric axis Followers.
  • Count each user.id once, even when the user wrote several collected tweets. If stored follower counts differ for that user, use the highest numeric count.
  • Use followers_count: the number of accounts following this user. Do not rank by following_count or by how many tweets the user wrote.
  • Put the largest value at the top and use a descriptive chart title. An additional table is optional.

In the Markdown answer, identify the leading user and describe how their follower count compares with the others in your chart.

Q3. Which profile locations occur among the most users? — 10 points

Write or adapt a query for the 10 most common non-empty profile locations, then use pandas to create a bar chart. Design your own title, labels, colors, and bar orientation.

  • Use user.location and count distinct user.id values, so a user with several tweets is counted once.
  • Exclude missing, null, empty, and whitespace-only locations. Trim surrounding spaces; keep the remaining spelling and capitalization as stored.
  • If a user has different non-empty location values, choose one consistently and explain your rule.
  • Label the count axis Distinct users. A table is optional.

In the Markdown answer, identify the leading location labels and explain that profile locations are self-reported text. For this lab, labels such as NYC and New York remain separate. If no usable locations exist, display the empty query result and explain why there is no chart.

Q4. Which hashtags occur most often? — 10 points

Reuse or revise your Lab 9 hashtag query to find up to 10 hashtags from tweet.entities.hashtags.tag. Bring the result into pandas and create a bar chart. Choose your own title, labels, colors, and bar orientation.

  • Count each tag's occurrences in the stored hashtag arrays. A tweet with two different hashtags contributes one occurrence to each.
  • Preserve stored spelling and capitalization, so Election and election remain separate.
  • Label the count axis Hashtag occurrences. A table is optional when you have hashtags to plot.
  • If only one or two hashtags occur, plot those one or two. If there are none, display the executed empty result and write “No hashtags found; hashtag occurrences: 0.” No chart is required for that empty result.

In the Markdown answer, describe the leading hashtags and what the counts measure. Do not invent hashtags, extract substitutes from tweet text, or add rows to make a fuller chart.

Small or incomplete results

Show all available qualifying results when there are fewer than ten. A missing or nonnumeric like/follower count is unknown, not zero; exclude it from the ranking and report how many were excluded. A correctly executed empty location or hashtag result can receive full credit. A connection error, failed query, or unexecuted cell does not establish an empty result.
