4. Answer the four questions — 40 points

Q1. Which ten collected tweets have the most likes? — 10 points

Create a pandas table with Tweet text on the left and Likes on the right. Display up to 10 unique tweets, from highest to lowest tweet.public_metrics.like_count.

  • Show the complete tweet.text, without truncation.
  • Count each tweet.id once. If repeated, use its highest stored numeric like count.
  • Use a consistent tie-break, such as sorting by tweet.id.

In the Markdown findings, describe what the most-liked posts discuss. These are stored counts from collection time, not live counts.

Q2. Which ten users in your collection have the most followers? — 10 points

Create a horizontal bar chart for up to 10 distinct users, ranked by user.public_metrics.followers_count.

  • Count each user.id once, even if the user wrote several collected tweets. Use the highest stored numeric follower count for that user.
  • Label the bars with user.username and the numeric axis Followers. Put the largest value at the top and use a descriptive title.
  • Do not rank by following_count or by the number of collected tweets.

In the Markdown findings, identify the leading user and compare their follower count with the others. An additional final table is optional.

Q3. Which profile locations occur among the most users? — 10 points

Create a bar chart for up to 10 non-empty profile locations, using user.location and counting distinct user.id values.

  • Exclude missing, null, empty, and whitespace-only locations. Trim surrounding spaces; otherwise preserve spelling and capitalization.
  • If one user has different non-empty locations, choose one consistently and explain the rule.
  • Label the count axis Distinct users. Choose a clear title and bar orientation.

In the Markdown findings, identify the leading location labels and explain that they are self-reported profile text. Labels such as NYC and New York remain separate. If no usable locations exist, display the successfully executed empty query result and explain why no chart is possible.

Q4. Which hashtags occur most often? — 10 points

Create a bar chart for up to 10 hashtags from tweet.entities.hashtags.tag. Use MongoDB AI to build and check the required array aggregation.

  • Count each tag's occurrences in the stored hashtag arrays. A post with two different tags contributes one occurrence to each.
  • Preserve spelling and capitalization: Election and election remain separate.
  • Label the count axis Hashtag occurrences. Choose a clear title and bar orientation.

Describe the leading tags and what the counts measure. If only one or two tags occur, plot those. If none occur, display the successfully executed empty result and write “No hashtags found; hashtag occurrences: 0.” No chart is required for that valid empty result. Do not invent hashtags, extract substitutes from text, or add rows for a fuller chart.

Small or incomplete results

Show all qualifying results when there are fewer than ten. Missing or nonnumeric like/follower counts are unknown, not zero; exclude them from rankings and report the number excluded. Correctly executed and explained empty results can earn full credit. A connection error, failed query, or unexecuted cell does not establish an empty result.
