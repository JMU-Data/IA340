Questions

  1. Total tweets: How many tweets have you collected?
  2. Users with locations: How many users provide a non-empty location? Count each user.id once.
  3. Text search: How many tweets match Trump using $text on tweet.text?
  4. Most-followed user: Which user has the most followers? Give the name, username, and follower count.
  5. Most popular hashtag: What is the most common hashtag, and how many times does it occur? Count tweet.entities.hashtags.tag as stored. If there are none, report None and 0.

For a tie, you may report any one of the tied users or hashtags.
