Step 12

12 — Slice Rows by Position

Use iloc when you want rows by their integer positions:

first_ten_rows = covid.iloc[0:10]
        first_ten_rows

Read the slice as: start at position 0, stop before position 10.

The result contains ten rows. Slicing does not ask whether the values meet a condition.

Step 13

13 — Filter Rows with One Condition

Suppose we want records with more than 1,000 reported deaths:

high_death_days = covid[
            covid["deaths"] > 1000
        ]
        
        high_death_days.head()

The expression inside the brackets creates a Boolean condition: True keeps the row; False removes it.

Step 14

14 — Select Columns after Filtering

We usually do not need every column in the filtered result:

high_death_days = high_death_days[
            ["date", "country", "cases", "deaths"]
        ]
        
        high_death_days.head()

This is easier to read as two operations: 1. filter the rows 2. select the useful columns

Step 15

15 — Combine Two Conditions

Use & when both conditions must be true:

usa_high_cases = covid[
            (covid["country"] == "United_States_of_America")
            & (covid["cases"] > 100000)
        ]
        
        usa_high_cases.head()

Important syntax: place each condition inside parentheses; use & for AND; use | for OR; use == to test equality.

Step 18

18 — Why We Need groupby()

Suppose the question is:

How many cases were reported worldwide on each date?

The original table has many rows for each date—one row for every reporting country.

We need to:

put rows with the same date together
        → add the cases inside each date group
        → return one result row for each date

That is the basic purpose of groupby() plus an aggregation function.

Step 20

20 — Default GroupBy: as_index=True

A pandas index is the set of row labels. By default, groupby() uses as_index=True, so the grouping key becomes the result index:

by_country_index = (
            covid
            .groupby("country")
            .agg(total_cases=("cases", "sum"))
        )

Conceptually, the result looks like:

index (country)        total_cases
        Argentina              ...
        Brazil                 ...
        Canada                 ...

The country labels live in the index, not in a data column.

Step 20

20 — Keeping Columns: as_index=False

For this course, we often use as_index=False:

by_country_columns = (
            covid
            .groupby("country", as_index=False)
            .agg(total_cases=("cases", "sum"))
        )

Now country stays a normal column, and pandas keeps a simple numeric row index:

index   country        total_cases
        0       Argentina      ...
        1       Brazil         ...
        2       Canada         ...

Why use as_index=False? It makes the summary easier to display, export, merge, and plot with plot(x="country", y="total_cases").

Step 21

21 — A Simple GroupBy and Sum

daily_cases = (
            covid
            .groupby("date", as_index=False)["cases"]
            .sum()
            .sort_values("date")
        )
        
        daily_cases.head()

Read it in order:

group by date
        → select cases
        → add cases inside each date group
        → sort the result by date

The original grain was one country-date row. The new grain is one row per date.

Step 22

22 — Aggregate More Than One Metric

daily_global = (
            covid
            .groupby("date", as_index=False)
            .agg(
                total_cases=("cases", "sum"),
                total_deaths=("deaths", "sum"),
            )
            .sort_values("date")
        )
        
        daily_global.head()

agg() lets one groupby() calculate one or more summary metrics and assign clear output column names:

new column name = (source column, aggregation function)
Step 22

22 — agg() Rules and Colab Output

You can use functions such as sum, mean, max, min, and count depending on the research question.

Do not sum every numeric column automatically. For example, pop repeats on many dates, and cum is already a 14-day rate.

Step 23

23 — Work with Dates Using .dt

Because date was parsed as a datetime column, pandas can extract useful time units:

covid["year"] = covid["date"].dt.year
        covid["month"] = covid["date"].dt.to_period("M").astype(str)
        covid["quarter"] = covid["date"].dt.to_period("Q").astype(str)
        
        covid[["date", "year", "month", "quarter"]].head()

Useful choices: - .dt.year → year number; - .dt.month → month number from 1 to 12; - .dt.to_period("M") → year-month unit such as 2020-04; - .dt.to_period("Q") → quarter such as 2020Q2.

Step 25

25 — Pandas Plotting Is a Simple Matplotlib Wrapper

Pandas provides plotting methods on a DataFrame or Series. The default backend is Matplotlib.

Start with the simplest line chart:

daily_cases.plot(x="date", y="cases")

A line chart is the default, so kind="line" is not required. This named form is equivalent:

daily_cases.plot.line(x="date", y="cases")

For other chart types, use the readable named methods: .plot.bar(), .plot.barh(), .plot.scatter(), .plot.hist(), .plot.box().

Step 26

26 — Line Plot: Change over Time

daily_cases.plot(
            x="date",
            y="cases",
            title="Worldwide Daily Reported COVID-19 Cases",
            xlabel="Date",
            ylabel="Reported cases",
            legend=False,
            figsize=(10, 5),
        )

Use a line plot when: - the x-axis has a meaningful order, usually time; and - the goal is to see change, peaks, declines, or repeated patterns.

Step 30

30 — Match the Chart to the Question

Question type Best starting chart
How does a value change over time? line
How do categories compare? bar
How is one numeric value distributed? histogram or box
How are two numeric variables related? scatter

Examples: - cases by month → line or bar; - total deaths by country → bar; - distribution of daily cases for one country → histogram or box; - daily cases versus daily deaths → scatter.

Step 33

33 — What Makes a Research Question Usable?

A usable question: - can be answered with the available columns; - names a country, metric, grouping, or time period; - leads to a result that can be calculated and displayed; - can be answered with specific values from the output.

Good examples: - Which month had the highest total reported cases in this country? - During which quarter was the average 14-day rate highest? - How did monthly reported deaths change during 2020?

Too vague:

What happened with COVID-19?
