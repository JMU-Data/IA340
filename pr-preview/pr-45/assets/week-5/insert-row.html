What do cursor and connection mean?
conn owns this database session and transaction. cur = conn.cursor() creates an object for sending SQL through that session. execute is called on cur; commit is called on conn.
After committing, cur.close() closes the cursor and conn.close() closes this notebook's connection. These are not database deletion commands. No disconnect button is needed to learn the two main actions.
