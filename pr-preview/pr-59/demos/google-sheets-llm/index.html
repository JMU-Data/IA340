Six AI columns to copy down

These prompts operate on the same row. Text analysis uses A2; latitude and longitude use B2. Each formula should be checked after generation.

C
SentimentPositive / Neutral / Negative
=AI("Classify the sentiment of the message as Positive, Neutral, or Negative. Return one label only.", A2)
D
Anger?True / False / Unknown
=AI("Does this message express anger? Return only True, False, or Unknown.", A2)
E
OrganizationsNamed entities
=AI("Extract only explicitly named organizations in this text. Separate multiple names with semicolons. If none, return None.", A2)
F
SummaryShort English summary
=AI("Summarize this message in one short sentence of at most 12 words. Return only the summary.", A2)
G
LatitudeApproximate, unverified
=AI("Estimate the latitude for this street address in decimal degrees. Return only one number, or Unknown if uncertain. Do not add explanations.", B2)
H
LongitudeApproximate, unverified
=AI("Estimate the longitude for this street address in decimal degrees. Return only one number, or Unknown if uncertain. Do not add explanations.", B2)
Teaching distinction: extraction vs. geocoding. An LLM may invent or approximate coordinates, even for a real address. The latitude and longitude are an experiment in LLM behavior, not GIS-quality geocoding. Also, Sheets’ =AI() access and generation quotas vary by account; students without access can still follow the demonstration.
